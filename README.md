## Características Destacadas

Este proyecto no es solo una página estática, incluye varias implementaciones técnicas y visuales:

* **Diseño UI/UX Personalizado:** Una estética "Oscuro-Morado" que combina fondos azul oscuro con tonalidades lila/morado, reflejando mi identidad visual como desarrolladora.
* **Animaciones CSS:** Integración de animaciones fluidas, incluyendo un fondo inmersivo y dinámico con estrellas flotantes y giratorias (aceleradas por hardware para no afectar el rendimiento).
* **Diseño Responsivo:** Adaptable a todo tipo de pantallas (móviles, tablets y escritorio).

---

## Tecnologías Usadas

El portafolio en sí mismo está construido utilizando tecnologías web estándar, sin depender de frameworks pesados, para garantizar tiempos de carga rápidos:

* **HTML5:** Estructura semántica.
* **CSS3:** Estilos, variables CSS (Custom Properties), Flexbox/Grid y animaciones `@keyframes`.
* **JavaScript (Vanilla):** Lógica de interacción, generación dinámica de elementos (como el fondo de estrellas) y manipulación del DOM.
* **GitHub Pages:** Despliegue y hosting continuo.

*(Nota: Dentro del portafolio se documentan otras tecnologías de backend y nube que manejo, como C#, Java, Python, AWS, bases de datos, etc.).*

---

## Estructura del Proyecto

El repositorio tiene una arquitectura limpia y directa:

```text

```

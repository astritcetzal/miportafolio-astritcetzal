Magic Library

De que trata: Plataforma web disenada para ayudar a desarrollar y mantener el habito de la lectura.

Como funciona:

Motor de Metas de Lectura con calculo en tiempo real.

Gestion de inventario literario (Terminados, En Proceso, Pendientes).

Recomendaciones inteligentes mediante consumo de APIs de LLMs.

Sistema de alertas asincronas con Background Services (IHostedService).

Stack: ASP.NET Core, C#, Entity Framework Core, SQL Server, AWS RDS, Elastic Beanstalk.

Menu Area Refrescante

Como funciona:

Exposicion segura del servicio mediante AWS API Gateway.

Consumo de API en frontend con JavaScript Fetch inyectando datos al DOM.

Stack: Python, AWS Lambda, DynamoDB, API Gateway, JavaScript, HTML, CSS, GitHub Pages.

Restaurant Backend API

De que trata: API RESTful para administracion integral de ordenes, mesas y catalogo gastronomico.

Como funciona:

Arquitectura en Capas DDD (Web, Dominio y Persistencia).

Persistencia en PostgreSQL mediante Spring Data JPA y mapeo con MapStruct.

Autenticacion sin estado con JWT y documentacion OpenAPI/Swagger.

Stack: Java, Spring Boot, PostgreSQL, Spring Data JPA, JWT, MapStruct, Swagger.

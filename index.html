Magic Library

De qué trata: Plataforma web diseñada para ayudar a desarrollar y mantener el hábito de la lectura.

Cómo funciona:

• Motor de Metas de Lectura con cálculo en tiempo real.

• Gestión de inventario literario (Terminados, En Proceso, Pendientes).

• Recomendaciones inteligentes mediante consumo de APIs de LLMs.

• Sistema de alertas asíncronas con Background Services (IHostedService).

Stack: ASP.NET Core, C#, Entity Framework Core, SQL Server, AWS RDS, Elastic Beanstalk.

Menú Área Refrescante

De qué trata: Aplicación web serverless para digitalización del menú de bebidas.

Cómo funciona:

• Almacenamiento NoSQL en Amazon DynamoDB.

• Lógica backend con función AWS Lambda en Python 3.12 y políticas IAM estrictas.

• Exposición segura del servicio mediante AWS API Gateway.

• Consumo de API en frontend con JavaScript Fetch inyectando datos al DOM.

Stack: Python, AWS Lambda, DynamoDB, API Gateway, JavaScript, HTML, CSS, GitHub Pages.

Restaurant Backend API

De qué trata: API RESTful para administración integral de órdenes, mesas y catálogo gastronómico.

Cómo funciona:

• Arquitectura en Capas DDD (Web, Dominio y Persistencia).

• Persistencia en PostgreSQL mediante Spring Data JPA y mapeo con MapStruct.

• Autenticación sin estado con JWT y documentación OpenAPI/Swagger.

Stack: Java, Spring Boot, PostgreSQL, Spring Data JPA, JWT, MapStruct, Swagger.
